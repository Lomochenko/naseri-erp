# اصلاح رابط و عملکرد — ۱ اکتبر ۲۰۲۶

این تغییرات مشترکِ کد ناصری و دهقان هستند؛ هیچ دیتابیس واقعی، رمز، فایل `.env` یا برنامهٔ هاست در این مرحله تغییر نکرده است.

## تغییرات

- فایل‌های موقت Python (`__pycache__` و `.pyc`، ۷۴ فایل) از پیگیری Git خارج شدند. نسخه‌های محلی باقی می‌مانند و قواعد موجود `.gitignore` مانع ثبت مجددشان می‌شود.
- رنگ‌های مفقود قالب قدیمی Tailwind تعریف و متن، ورودی، جدول و پنجره‌های اصلی در حالت تاریک اصلاح شدند.
- دکمهٔ نمایش رمز یک دکمهٔ مستقل و قابل‌دسترسی ۴۴×۴۴ است؛ فضای امن در ورودی RTL دارد و کلیک روی ورودی، رمز را آشکار نمی‌کند.
- پوستهٔ مدیریت بین مسیرها ثابت است. محتوای صفحه با گذار ۱۷۰ میلی‌ثانیه تغییر می‌کند؛ تغییر query، عقب/جلو مرورگر و ترجیح کاهش حرکت پشتیبانی می‌شوند.
- عکس ساختگی کاربر و کنترل بارگذاریِ بدون پشتیبانی حذف شدند؛ حروف نام کاربر جایگزین عکس است.
- دسترسی سریع داشبورد به کارت‌های آبیِ کالا، سبزِ فروش و کهرباییِ موجودی تبدیل شد.
- جست‌وجوی سربرگ دیگر چهار فهرست را در شروع بارگیری نمی‌کند. پس از دو نویسه و توقف تایپ ۳۰۰ میلی‌ثانیه، دو جست‌وجوی کوچک و هم‌زمان روی کالا/مشتری انجام می‌دهد. درخواست قبلی لغو و پاسخ قدیمی نادیده گرفته می‌شود؛ خطای شبکه از «نتیجه‌ای نیست» متمایز است.
- API جست‌وجو با `lookup=true` فقط فیلدهای موردنیاز را برمی‌گرداند و همچنان احراز هویت می‌خواهد. `page_size` قابل تنظیم و حداکثر ۱۰۰ است؛ پیش‌فرض ۱۰ باقی است.
- فهرست کالا از جمع موجودی در یک query و روابط ازپیش‌دریافت‌شده استفاده می‌کند؛ فهرست فروش نیز ردیف‌ها/روابط را پیش‌دریافت و جمع را یک‌جا محاسبه می‌کند. عملیات ثبت، پرداخت و قواعد مالی تغییر نکرده‌اند.
- اعلان‌ها حداقل یک دقیقه تازگی دارند، در تب مخفی درخواست نمی‌فرستند و هنگام خطا با فاصلهٔ افزایشی تلاش می‌کنند. خطا دادهٔ قبلی را پاک نمی‌کند؛ کش به نشست کاربر محدود است و تلاش دستی فاصلهٔ انتظار را دور می‌زند.
- فونت متغیر Vazirmatn همراه سایت (۱۱۱٬۱۵۲ بایت، با مجوز OFL) بارگیری و پیش‌بارگذاری می‌شود. وابستگی فونت به Google/CDN حذف شد، از جمله مسیر کمکی PDF.
- نمودار و انتخابگر تاریخ هنگام نیاز بارگیری می‌شوند؛ ابزار توسعه در خروجی production قرار نمی‌گیرد. لاگ‌های نمایشی فروش در مرورگر حذف شدند.
- دو لاگ نامناسبِ ورود که دادهٔ رمز و توکن را در خروجی سرور چاپ می‌کردند حذف شدند؛ روش ورود تغییر نکرده است.

## بررسی‌ها

- `python manage.py test --settings=naseri_erp.test_settings --noinput`: ۱۲۱ تست موفق؛ دیتابیس SQLite موقت و بدون خواندن `.env`.
- چهار تست جدید: موجودی با هر شش نوع تراکنش و تعداد query ثابت، جست‌وجوی محدود و احراز هویت، جمع/تخفیف/مالیات فروش و سقف صفحه‌بندی.
- تعداد query برای صفحهٔ ۱۲ کالا حداکثر ۳، برای ۱۲ فروش حداکثر ۴ و هر جست‌وجوی کوچک حداکثر ۲ است.
- `makemigrations --check --dry-run`: تغییر schema وجود ندارد.
- ساخت production برای هر دو برند و بررسی whitespace انجام می‌شود.
- تست مرورگر محلی با API ساختگی در عرض‌های ۳۷۵، ۷۶۸ و ۱۴۴۰ انجام شد. ورود با کلیک/کیبورد، حالت روشن/تاریک، حفظ پوسته، عقب/جلو، کاهش حرکت، لغو جست‌وجوی قدیمی و صفحات عملیاتی بررسی شدند. ارزیابی نهایی پس از سه مرحله PASS شد؛ تست‌ها روی دادهٔ زنده اجرا نشده‌اند. ارزیاب مستقل بود، اما مدلِ ارائه‌دهندهٔ دیگری در دسترس نبود.
- حجم entry اصلی پس از lazy-loading تقریباً ۲۴۹ کیلوبایت در برابر حدود ۱٬۱۳۸ کیلوبایت قبل از تغییر است (حجم خام build، نه اندازهٔ کل سایت). کتابخانه‌های PDF/نمودار همچنان chunkهای بزرگِ هنگام‌نیاز دارند.
- هشدارهای قبلی تست دربارهٔ پوشهٔ staticfiles محلی، min_value و ترتیب صفحه‌بندی Report باقی‌اند؛ شکست تست یا migration جدید وجود ندارد.

## محدودیت و انتشار

پیام `runtime.lastError: Receiving end does not exist` معمولاً مربوط به ارتباط افزونهٔ مرورگر است؛ بدون تست مرورگرِ بدون افزونه، علت قطعی مشخص نیست. خطاهای Axios واقعی‌اند و باید پس از انتشار، با نشست واردشده دوباره اندازه‌گیری شوند. کاهش درخواست‌ها و هزینهٔ query، تضمین رفع مشکل شبکه یا محدودیت هاست نیست.

در بررسی فقط‌خواندنیِ سایت فعلی، صفحهٔ اصلی HTTP 200 و API بدون احراز هویت HTTP 401 داشتند، با زمان پاسخ اولیه حدود ۱٫۵–۱٫۷ ثانیه. این بررسی، عملکرد API واردشده را اندازه‌گیری نمی‌کند.

انتشار باید شامل بک‌اند و فرانت‌اندِ هر دو کسب‌وکار باشد؛ بستهٔ فرانت‌اند هر برند فقط در پوشهٔ همان دامنه منتشر شود. `.env`، `.htaccess` هاست، فایل‌های رسانه و دیتابیس‌ها را جایگزین نکنید. این تغییر migration جدید یا وابستگی Python تازه ندارد. پیش از عملیات انتشارِ دارای دادهٔ واقعی، نسخهٔ پشتیبان بگیرید.
