# نوار پایین موبایل

طراحی اختصاصیِ سبک برای رابط فارسی ناصری و دهقان، بدون کتابخانهٔ جدید یا تغییر بک‌اند.

## دسترسی‌ها

- خانه: داشبورد
- فروش: فهرست فروش
- ثبت جدید: پنجرهٔ انتخاب فروش جدید، خرید جدید یا کالای جدید
- موجودی: صفحهٔ موجودی
- بیشتر: مشتریان، خرید و کالاها؛ گزارش و پروفایل با برچسب «به‌زودی» غیرفعال‌اند.

فروش و خرید جدید، فرم‌های فعلی برنامه را باز می‌کنند. قصد ثبت در حافظهٔ موقت نگه‌داری و یک‌بار مصرف می‌شود؛ در URL، تاریخچه یا localStorage ذخیره نمی‌شود. رفت‌وبرگشت مرورگر فرم جدید را دوباره باز نمی‌کند و هیچ رکوردی تا ارسال دستی فرم ثبت نمی‌شود.

## ظاهر و رفتار

نوار پنج‌گزینه‌ای با دکمهٔ برجستهٔ آبی، گوشه‌های نرم، آیکون‌های خطی، عنوان فارسی و نشان صفحهٔ فعال؛ منوی کشویی پایین با گزینه‌های رنگی. هر دو حالت روشن و تاریک، RTL، حاشیهٔ امن پایین گوشی، هدف لمس مناسب، فوکوس کیبورد، Escape، کاهش حرکت و فاصلهٔ کافی از آخر محتوا در نظر گرفته شده‌اند.

فقط زیر عرض ۷۶۸ پیکسل نمایش داده می‌شود. روی صفحهٔ ورود، فاکتور عمومی و چاپ ظاهر نمی‌شود. هنگام بازشدن سایدبار، پنجرهٔ شناور موجود یا ورود متن/نمایش کیبورد مخفی می‌شود. چرخش صفحه نباید با کیبورد اشتباه گرفته شود.

## فایل‌ها

- `frontend/src/components/layout/MobileBottomNav.vue`: نوار، منوها و رفتارهای دسترسی
- `frontend/src/composables/useQuickCreate.js`: قصد موقتِ بازکردن فرم
- `frontend/src/components/layout/AdminLayout.vue`: اتصال نوار به پوسته و فاصلهٔ پایین محتوا
- `frontend/src/components/sales/SalesOrderList.vue`: بازکردن فرم فروش
- `frontend/src/views/Purchases/PurchasesList.vue`: بازکردن فرم خرید

## ساخت و انتشار

ناصری با `npm run build` و دهقان با `npm run build:dehghan` ساخته می‌شود. بستهٔ هر برند فقط به دامنهٔ خودش تعلق دارد. این تغییر migration یا وابستگی جدید ندارد. فایل‌های `.env` و `.htaccess` هاست و داده‌های واقعی نباید جایگزین شوند.

## بررسی انجام‌شده

ساخت production هر دو برند و `git diff --check` موفق بود. ارزیابی مستقل محلی پس از اصلاح رنگ‌های تاریک در مرحلهٔ دوم PASS شد. عرض‌های ۳۲۰، ۳۷۵، ۴۳۰، ۷۶۸ و ۱۴۴۰ پیکسل، روشن/تاریک، عدم سرریز افقی، اهداف لمس (حداقل ۵۷×۵۴ پیکسل برای نوار)، بازشدن فرم فروش/خرید در مسیر جدید و همان مسیر، عدم بازشدن مجدد فرم با تاریخچه، مسیر کالای جدید، منوی بیشتر، Escape/Tab/بازگشت فوکوس/قفل اسکرول و مخفی‌شدن در ورودی/سایدبار/پنجره/چاپ/ورود/فاکتور عمومی بررسی شدند.

همهٔ تست‌ها با نشست و API ساختگی انجام شدند؛ هیچ ارسال فرم یا نوشتن روی سایت واقعی صورت نگرفت. کنترل inspector توسعه فقط در تصاویر QA مخفی شد؛ در build تولیدی اساساً فعال نیست. ارزیاب مستقل بود، اما مدلِ ارائه‌دهندهٔ دیگری در دسترس نبود.

فایل اصلی جاوااسکریپت اکنون حدود ۲۶۲٫۴ کیلوبایت است؛ افزایش حدود ۱۳ کیلوبایت مربوط به نوار و آیکون‌هاست و کتابخانهٔ جدیدی نصب نشده است. هشدار اندازهٔ chunkهای PDF/نمودار هنگام‌نیاز همچنان وجود دارد.

تست کیبورد و حاشیهٔ امن روی گوشی واقعی پس از انتشار توصیه می‌شود؛ شبیه‌سازی مرورگر جای تست دستگاه واقعی را نمی‌گیرد.
